# Modul AI Deployment untuk Pemimpin

Modul praktis untuk merancang, menjalankan, mengukur, dan mengevaluasi deployment
serta adopsi AI di organisasi. Modul dimulai dari **strategi**: enam framework
strategi AI untuk pemimpin. Setelah itu, modul membahas **kesiapan**, **arsitektur**,
**desain agentic AI**, serta **pengukuran dan evaluasi** deployment dan adopsi.

> Prinsip utama: **mulai dari keputusan, baru pilih framework-nya.**
> Framework adalah alat bantu berpikir, bukan tujuan.

## Cara Menggunakan

- **Workshop eksekutif (1 hari):** Modul 1 (pagi), lalu Modul 2 (siang), ditutup dengan AI Strategy Canvas.
- **Program deployment (3–6 bulan):** Modul 1–5 berurutan, dengan review bulanan memakai Modul 5.
- **Evaluasi program yang sudah berjalan:** mulai dari Modul 5, lalu kembali ke Modul 1 untuk re-prioritisasi.

## Target Peserta

C-level, kepala unit bisnis, tim transformasi/PMO, IT/data lead, HR/L&D, serta
tim risk & compliance.
